# WXT + React

This template should help get you started developing with React in WXT.

## Android Mobile Support

This extension now includes comprehensive Android mobile support:

### Supported Mobile Browsers
- **Firefox for Android** - Full extension support with mobile-optimized UI
- **Kiwi Browser** - Chromium-based mobile browser with extension support  
- **Samsung Internet** (limited) - Some versions support extensions
- **Microsoft Edge Mobile** (limited) - Limited extension support

### Mobile Optimizations
- **Responsive Design**: Popup and options pages automatically adapt to mobile screen sizes
- **Touch-Friendly UI**: Larger touch targets (minimum 44px) for better mobile interaction
- **Performance**: Reduced batch sizes for mobile devices to conserve memory and battery
- **Adaptive Text**: Button labels and content adjust for smaller screens
- **Mobile Detection**: Automatic detection of mobile environment for optimized experience

### Installation on Mobile
1. Install a compatible browser (Firefox for Android or Kiwi Browser recommended)
2. Enable extension/add-on support in browser settings
3. Load the extension via developer mode or install from browser store
4. Extension popup and options will automatically adapt to mobile interface

### Development
The extension uses responsive CSS with mobile-first approach and includes browser detection via the Bowser library for optimal mobile experience.
