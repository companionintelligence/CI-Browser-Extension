# Running CI for this repo

Automatic workflow triggers in this repository are **live again**: pushing to
`master` and opening a pull request against it start GitHub-hosted runs, exactly
as they did before 2026-08-01.

Background: `ci-local` gated every trigger in this repo down to
`workflow_dispatch` on 2026-08-01 to cut a $563/month org-wide Actions bill, but
it was applied indiscriminately. This repo's entry in
`CI-Local-CICD/.ci-local-baseline.json` lists `"billing": []` — none of its
workflows were among the ones actually costing money. Measured July 2026 usage
for the whole repo was 140 runs / 97.8 runner-minutes, so gating it saved on the
order of a dollar a month while leaving a release-critical extension with no
automatic checks.

Default branch: `master`

### Test locally

```bash
ci-local run --repo CI-Browser-Extension
```

Equivalent to:

```bash
yarn install --immutable
yarn run lint
yarn run test
yarn run build
```

### Automatic

These run without being asked - no action needed:

- **Build and Test** — `build-and-test.yml`, on push to `master` and on pull
  requests targeting `master`
- **Style canon lint** — `style-canon-lint.yml`, on every push and every pull
  request
- **Release** — `release.yml`, on pushing a `v*` tag

### Still manual, on purpose

Starting these needs the [`gh` CLI](https://cli.github.com) and push access.
`--ref` matters - the workflow file is read from that branch, so a workflow that
only exists on your feature branch must be dispatched against it.

**Verify Store Credentials** — `verify-store-credentials.yml`. Read-only check
that the store-publish secrets used by `release.yml` are valid. Run it after
adding or rotating a store secret; it never uploads or submits anything.

```bash
gh workflow run verify-store-credentials.yml --repo companionintelligence/CI-Browser-Extension --ref master
```

**Build and Test (Deno)** — `build-and-test-deno.yml`. The parallel Deno
build/lint/test path added in #98. Manual until that path has had a human review
pass; it does not replace `build-and-test.yml`.

```bash
gh workflow run build-and-test-deno.yml --repo companionintelligence/CI-Browser-Extension --ref master
```
