🛠️ Template System

Scalable Architecture: The system includes profile templates for:

  • Streaming Services
  • Social Media Platforms
  • News & Media Sites
  • E-commerce Platforms
  • Financial Services
  • Travel & Booking Sites
  • Gaming Platforms

New sites can be added by using templates or creating custom profiles with JSON configuration.

🔧 Technical Implementation

  • ProfileManager: Dynamically loads profiles organized by category
  • Content Script: Automatically matches against all supported domains
  • Profile Templates: Systematic approach to creating new site profiles
  • Data Transforms: Built-in data cleaning and URL resolution
  • Privacy Categories: Organized data types for privacy compliance
